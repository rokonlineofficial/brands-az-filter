=== Brands A-Z Filter ===
Requires at least: 5.6
Tested up to: 6.7
Requires PHP: 7.4
Stable tag: 1.0.0
License: GPL-2.0-or-later

"Shop By Brand" page with an A-Z letter filter, View All and brand search.

== Usage ==
Add the shortcode to any page (Elementor: Shortcode widget):

[brands_az]

Optional attributes:
taxonomy="product_brand"  (override brand taxonomy)
hide_empty="no"           (show brands that have no published products)
merge="no"                (do not merge brands with the same name)
search="no"               (hide the search box)
view_all="no"             (hide the View All button)
columns="3"               (1 to 4 columns, default 2)

Colors and taxonomy: Settings > Brands A-Z.
